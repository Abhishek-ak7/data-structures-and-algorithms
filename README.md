# Data Structures & Algorithms Playground

A Java-focused repository for solving algorithmic problems with clarity, structure, and visual intuition. This project is built around classic interview patterns such as sliding window, two pointers, frequency counting, prefix sums, and greedy reasoning — all implemented in Java and paired with interactive visual explanations where possible.

## Why this project exists

This repository is designed for learning by doing. Instead of only memorizing formulas, each problem is treated as a practical challenge:

- understand the pattern behind the problem
- choose the correct algorithmic approach
- implement the solution in Java
- verify correctness with examples and edge cases
- explain the logic in a readable, visual way

The result is a collection that feels both educational and practical, useful for interviews, competitive programming, and everyday algorithm practice.

## Highlights

- Java implementations for real-world coding interview problems
- Sliding window and two-pointer patterns emphasized throughout the repo
- Focus on time complexity and space complexity analysis
- Visualizer sandboxes for selected problems to make logic more intuitive
- Clean folder structure that separates each problem and its explanation

## How to use this repository

1. Open any problem folder.
2. Read the local README for the problem description and reasoning.
3. Study the Java solution.
4. Run the file in your preferred Java environment.
5. If available, open the sandbox app to visualize the algorithm in motion.

### Typical Java run flow

```bash
cd length_of_longest_subarray_with_at_most_K_frequency_2958
javac Solution.java
java Solution
```

If your environment is configured with package declarations, you can also run it with the project classpath, for example:

```bash
javac -d . length_of_longest_subarray_with_at_most_K_frequency_2958/Solution.java
java length_of_longest_subarray_with_at_most_K_frequency_2958.Solution
```

## Learning philosophy

This project is not just about finishing a problem. It is about seeing the idea behind the solution:

- why a sliding window works
- when a hash map is the right tool
- how a constraint changes the algorithm choice
- what the real time and space trade-offs are

That is what makes the repo valuable beyond a collection of code snippets.

## Suggested roadmap

If you want to practice systematically, consider this order:

1. Start with easier substring and subarray problems
2. Move to sliding window problems with frequency counting
3. Learn prefix-sum and binary-search variants
4. Practice greedy and optimization patterns
5. Revisit difficult problems using the visual explanations to deepen understanding

## Final note

This repository reflects a problem-solving journey: each folder is a small step toward stronger algorithmic thinking. The goal is not only to produce working Java code, but to build practical intuition that helps in interviews, coding contests, and real engineering work.

If you are learning DSA seriously, this project is a strong foundation for building pattern recognition and implementation confidence.
